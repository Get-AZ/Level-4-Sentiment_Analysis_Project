# Application Usage

## Installation

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Launch

Start the Streamlit application:

```bash
streamlit run app.py
```

## Prediction

The application accepts review text and returns:

- Predicted sentiment
- Probability
- Confidence

## Sentiment Labels

- Positive
- Negative

## Confidence Threshold

The validated recommended confidence threshold is 70%.

The threshold provides:

- 98.51% coverage
- 92.51% accuracy

## Batch Processing

The application supports uploaded review data where implemented by
the validated Streamlit interface.
