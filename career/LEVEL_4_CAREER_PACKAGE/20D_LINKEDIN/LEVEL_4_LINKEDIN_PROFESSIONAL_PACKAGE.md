# LinkedIn Professional Package

## Project Title

Transformer-Based Sentiment Analysis with DistilBERT

## Project Description

Built and validated a Transformer-based binary sentiment-analysis system
for movie reviews using DistilBERT, Hugging Face Transformers, and PyTorch.

The project progressed from a traditional TF-IDF baseline to a fine-tuned
Transformer model.

### Certified Results

- 91.97% accuracy
- 91.90% precision
- 92.12% recall
- 92.01% F1
- 97.49% ROC-AUC

The TF-IDF baseline achieved 90.04% accuracy. DistilBERT achieved
91.97%, representing an observed 1.93 percentage-point improvement on
the evaluated benchmark.

I also performed confidence and reliability analysis. A validated
70% confidence threshold provided 98.51% coverage and 92.51% accuracy
on the evaluated data.

For inference, I packaged the model using Hugging Face Transformers,
PyTorch, AutoTokenizer, AutoModelForSequenceClassification, and Streamlit.

The project was published through a controlled GitHub release with
reproducibility evidence, SHA256 integrity verification, documentation
validation, claim governance, and large-model-file protection.
