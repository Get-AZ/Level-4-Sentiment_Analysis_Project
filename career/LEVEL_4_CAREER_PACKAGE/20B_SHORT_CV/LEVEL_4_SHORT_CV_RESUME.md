# Transformer-Based Sentiment Analysis — DistilBERT

**Python | NLP | Transformers | PyTorch | Scikit-learn | Streamlit | Git/GitHub**

- Built an end-to-end binary movie-review sentiment-classification
  system using a fine-tuned DistilBERT Transformer.
- Achieved **91.97% accuracy, 91.90% precision, 92.12% recall,
  92.01% F1, and 97.49% ROC-AUC**.
- Established a **90.04% TF-IDF baseline** and measured a
  **1.93 percentage-point accuracy improvement** with DistilBERT.
- Validated a **70% confidence threshold** with **98.51% coverage**
  and **92.51% accuracy** on the evaluated data.
- Packaged inference using Hugging Face Transformers, PyTorch,
  AutoTokenizer, AutoModelForSequenceClassification, and Streamlit.
- Published a controlled GitHub release with reproducibility evidence,
  SHA256 integrity verification, claim governance, and large-model-file
  protection.
