# Portfolio Project Summary

## Project Title

Production-Ready Sentiment Analysis with DistilBERT

## Summary

Developed an end-to-end NLP sentiment-analysis system using the IMDB
movie-review dataset, progressing from classical TF-IDF machine-learning
baselines to transformer-based DistilBERT classification.

## Key Achievement

DistilBERT achieved 91.97% accuracy and 92.01% F1 score, improving
accuracy by 1.93 percentage points over the TF-IDF baseline.

## Technical Skills Demonstrated

- Natural Language Processing
- Text preprocessing
- TF-IDF feature engineering
- N-gram analysis
- Word embeddings
- Transformer architectures
- DistilBERT fine-tuning
- PyTorch
- Hugging Face Transformers
- Model evaluation
- Confidence analysis
- Streamlit deployment
- Reproducibility
- Model integrity validation
- Production packaging

## Final Performance

- Accuracy: 91.97%
- Precision: 91.90%
- Recall: 92.12%
- F1: 92.01%
- ROC-AUC: 97.49%

## Deployment

The final model is integrated into a Streamlit application supporting
interactive sentiment prediction and confidence reporting.

## Production Readiness

The project passed final structural, performance, confidence, artifact,
reproducibility, integrity, and deployment validation.
